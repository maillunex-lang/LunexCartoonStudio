# GDD-01 · Рубеж 08 · Серверный сегментный рендер (PoC)

## Подтверждено на VPS Lunex
- FFmpeg 8.0.1 + libx264 + ffprobe установлены.
- CLI `integration/long-render/segmented-worker.mjs` умеет принимать JSON проекта (`LUNEX_PROJECT_FILE`), создавать независимые H.264 MP4-сегменты, записывать JSON-манифест с SHA-256 и попытками, пропускать проверенные готовые сегменты при перезапуске, объединять сегменты через FFmpeg concat и проверять число кадров через ffprobe.
- Импортированный JSON-проект с зелёным 3D-кубом и оранжевым 2D-слоем: 1.1 сек, 640×360, 30fps, 33 кадра. ffprobe и полное декодирование PASS, обе цветовые области есть в первом, среднем и последнем кадре.
- Демонстрационный проект: 2.0 сек, 60 кадров, MP4 PASS. Повторный запуск: SKIP готового сегмента, число попыток осталось 1.
- Планировщик: 6/6 тестов PASS, в том числе ограничение 300 секунд / 1080p / 30fps.

## Как запускать (локальный PoC, без публичного API)
```bash
cd /srv/lunex-cartoon-studio-poc/upstream
LUNEX_PLAYWRIGHT_PATH="$PWD/node_modules/playwright" \\
LUNEX_CHROME_PATH=/root/.cache/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell \\
LUNEX_PROJECT_FILE=/tmp/lunex-saved-project.json \\
LUNEX_JOB_DIR=/tmp/lunex-project-test \\
node /srv/lunex-cartoon-studio-poc/project/integration/long-render/segmented-worker.mjs
```

Результат: `$LUNEX_JOB_DIR/final.mp4`, `manifest.json`, `episode-00000.mp4` и далее. Для запуска более 30 секунд нужен `LUNEX_ALLOW_LONG_TEST=1`. Перед повторным запуском с другими параметрами или другим проектом укажи новый каталог задания.

## Известные ограничения
- Пока нет авторизованного API, очереди, UI-прогресса, изоляции и очистки файлов, обработки аудио, полного 2D-only и 2.5D режима.
- JSON импортируется из доверенного локального файла, а не из опубликованного веб-редактора.
- Перезапуск проверен только для завершённого сегмента. Прерывание посреди сегмента и восстановление ещё требуют тестов.
- Кадры берутся из браузерного viewport. Выравнивание и цветовые преобразования нужно проверить на разнообразных сценах.
- Для долгих прогонов нужно измерить время, нагрузку и объём временных файлов.
- Это не приёмка пятиминутного экспорта и не завершение GDD-01.
