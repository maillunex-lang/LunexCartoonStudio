# GDD-01 v2: Визуальный конструктор мультфильмов

**Статус: DRAFT / требуется выбор владельца.**

## Цель
Браузерная мультстудия в духе «Мульти-Пульти»: создавать 2D, 2.5D и 3D-сцены, выбирать персонажей и действия, перемещать объекты, воспроизводить эпизод и сохранять проект без знания Blender.

## Обязательное требование владельца: поддержка 2D и 3D
- Поддерживать полноценные 2D-мультфильмы (спрайты, изображения, слои, 2D-анимация) и 3D-мультфильмы (GLB/glTF, камеры, скелеты).
- Поддержать 2.5D (параллакс, слои на разной глубине) и гибридные сцены с 2D и 3D объектами.
- Единая модель проекта с типизированными объектами/слоями и независимыми рендерами; не сводить все проекты к GLB.
- При выборе движка обязательно сравнить MyMotionStudio (2D/3D), html5-game-editor (PixiJS/Three.js hybrid), PixelStage (2.5D); проверять лицензии и готовность именно анимационного таймлайна.
- Не объявлять смешанные сцены готовыми без отдельного интеграционного теста.

## Решения для утверждения
- **EDITOR-001**: A - только простой режим; B - простой + режиссёрский режимы с общими данными (рекомендация); C - только профессиональный режим.
- **ENGINE-001**: A - адаптировать подходящий open-source браузерный 3D-редактор после аудита (рекомендация); B - писать всё с нуля на Three.js; C - удалённый Blender в браузере.
- **SCENE-001**: A - сцены только в браузере без сохранения; B - версионированный JSON + 2D-ассеты (PNG/SVG/атласы) + GLB/GLTF для 3D и возможность повторного открытия (рекомендация); C - только Blender .blend.
- **TIMELINE-001**: A - последовательность готовых действий; B - готовые действия + редактируемые ключевые кадры и таймлайн (рекомендация); C - исключительно покадровая ручная анимация.
- **DEVICE-001**: A - только ПК; B - полноценное редактирование на ПК и адаптированный просмотр/простые правки на смартфоне (рекомендация); C - одинаковый полный 3D-редактор на всех экранах.
- **DEMO-001**: A - статичная комната; B - персонаж + комната + 3 движения + сохранение/загрузка + Play (рекомендация); C - сразу полноценная 3-минутная серия.

## После утверждения
Обязательно провести отдельный GitHub research с фиксацией проверенных лицензий, выбрать техническую основу и внедрить рабочее демо. Ни один найденный репозиторий пока не объявлен выбранным или интегрированным.

## Критерии приёмки GDD-01
1. Браузерный редактор с 2D-сценой и 3D-сценой, с переключением типа проекта.
2. Выбор и размещение объекта, хотя бы три анимационных действия.
3. Таймлайн или последовательность действий согласно утверждённому варианту.
4. Сохранение и загрузка проекта без потери сцены.
5. Проверенная сборка и smoke-тест.
6. Проверка 2.5D/гибридной сцены с 2D-слоем и 3D-объектом.
7. Демонстрация владельцу; этап закрывается только после его приёмки.
