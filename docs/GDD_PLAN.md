# Новый GDD-план v2

Статус: новый цикл, **0/10 этапов утверждено**. Предыдущий GDD и его решения сброшены по явному решению владельца; не считать их действующим каноном.

## Обязательный цикл каждого этапа
1. **DESIGN**: варианты A/B/C, рекомендации, критерии результата.
2. **APPROVAL**: владелец утверждает коды решений.
3. **RESEARCH**: поиск GitHub-проектов, готовых библиотек и решений; минимум 2-3 кандидата при наличии; документировать лицензии, активность, API, сложность и риски.
4. **TECH APPROVAL (обязательно)**: подготовить конкретный перечень «внедряем / адаптируем / пишем сами» с вариантами A/B/C, лицензиями, рисками и рекомендацией. Получить явное утверждение владельца **до любой интеграции**.
5. **IMPLEMENT**: интегрировать выбранное решение в рабочий проект, фиксировать коммиты и зависимости.
6. **TEST**: сборка, автоматические тесты, браузерный smoke, проверка экспорта и лицензий, воспроизводимая инструкция.
7. **ACCEPTANCE**: демонстрация и приёмка владельцем. Только после неё этап DONE и переход дальше.

## Этапы
- [ ] **GDD-01**: визуальный конструктор 2D/2.5D/3D сцен, простой и режиссёрский режимы, сохранение.
- [ ] **GDD-02**: персонажи, импорт/генерация моделей, скелеты и мимика.
- [ ] **GDD-03**: библиотека анимаций, лицензии, ретаргетинг, смешивание.
- [ ] **GDD-04**: локации, реквизит, камеры и освещение.
- [ ] **GDD-05**: сценарии, раскадровка, таймлайн и AI-режиссура.
- [ ] **GDD-06**: предпросмотр, рендер Blender, видеоэкспорт и производительность.
- [ ] **GDD-07**: портал, проекты/сериалы, UX и управление ассетами.
- [ ] **GDD-08**: Codex, Meshy AI, интеграции и безопасность.
- [ ] **GDD-09**: VPS, API, хранение, очередь задач, резервное копирование.
- [ ] **GDD-10**: QA, публикация, массовое производство и релиз.

Решения следующего этапа обсуждаем только после приёмки предыдущего, кроме явно согласованных сквозных изменений.
