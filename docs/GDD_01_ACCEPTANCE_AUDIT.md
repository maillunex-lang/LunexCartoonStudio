## Блокеры / технический долг
1. Простая/профессиональная оболочка.
2. Полноценная 2.5D/гибридная модель, пресеты действий/камер, готовые сцены.
3. Структура сериалов и версионирование.
4. DEVICE-001 A утверждено: полный редактор только на ПК, смартфон для просмотра проектов. Требуется тест просмотра, не разработка мобильного редактора.
5. Приёмочный E2E пользовательского проекта: создать → вставить 2D/3D → анимировать → сохранить → переоткрыть → экспортировать MP4 → ffprobe/декодировать → скачать.
6. Безопасность сервера: квоты/retention, контроль процессов при отмене, восстановление, backup. Отдельно планируются в GDD-09, но критичные для GDD-01 demo должны быть проверены.

## Порядок
- Не внедрять новые большие функции до сверки с утверждённым GDD.
- Закрывать GDD-01 блоками, показывать владельцу критерии и результат.
- Только после явного подтверждения владельца пометить GDD-01 DONE и перейти к GDD-02.
