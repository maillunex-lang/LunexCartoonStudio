# GDD Decisions - Lunex Cartoon Studio

## Утверждено
- **STUDIO-001 D**: автоматическая фабрика мультфильмов по сценарию, управляемая Codex.
- **ASSET-001 C**: гибрид Meshy AI (оригинальные модели) + готовые анимации с проверенной лицензией + Blender (ретаргетинг, сцены, рендер).

## GDD-01 - утверждено 2026-11-22
- **AUTO-001 A**: сценарий -> предпросмотр -> ручное утверждение -> финальный рендер.
- **EDIT-001 B**: редактирование текста и визуального таймлайна сцен.
- **OUTPUT-001 B**: горизонтальный 16:9 и вертикальный 9:16.
- **SCOPE-001 B**: любые жанры мультфильмов и разные сериалы на единой платформе.
- **APPROVAL-001 A**: финальный рендер только после обязательного утверждения предпросмотра.

## GDD-02 - утверждено 2026-11-22
- **CHAR-001 B**: у каждого мультсериала собственный style bible; платформа поддерживает несколько стилей.
- **MODEL-001 B**: создание оригинальных 3D-моделей через Meshy AI и импорт внешних лицензированных моделей.
- **RIG-001 B**: семейства скелетов (humanoid, quadruped, robot/custom) и ретаргетинг только между совместимыми профилями.
- **FACE-001 B**: управляемая мимика (blendshapes или лицевые кости), стандартные эмоции, возможность синхронизации речи.
- **QUALITY-001 B**: автоматическая техническая проверка модели плюс обязательное визуальное утверждение владельцем.
- **VARIANT-001 B**: повторно используемые варианты одежды, аксессуаров, материалов и цветов.

## GDD-03 - утверждено 2026-11-22
- **SOURCE-001 B**: бесплатные и платные лицензированные библиотеки плюс собственные анимации.
- **LIBRARY-001 B**: начать с целевого набора 50 клипов и расширять версионируемый каталог.
- **RETARGET-001 B**: ретаргетинг между совместимыми семействами скелетов, новые соответствия проходят проверку.
- **BLEND-001 B**: смешивание движений, слои жестов, переходы, IK и процедурное направление взгляда при технической поддержке.
- **LICENSE-001 B**: проверять происхождение, коммерческие права, атрибуцию и ограничения распространения до приёмки.
- **AUTHOR-001 B**: импорт, создание и редактирование анимаций в Blender с версиями.
- **PREVIEW-001 B**: автоматическая проверка, видеопревью и визуальное утверждение перед публикацией в общую библиотеку.

## Рабочие предположения, ещё не отдельные утверждённые решения
- Blender + Python + FFmpeg; FastAPI + PostgreSQL + React.
- Первая серия: Мишка, обучение счёту 1-10, 3 минуты, 16:9 1080p, без звука.
- Начальный каталог: целевой набор 50 анимаций, а не уже готовая библиотека.
- Сначала 15-секундный технический тест.
- Web Studio для каталогов, сценариев, предпросмотра и рендера.

Не менять утверждённые решения без согласования владельца.
