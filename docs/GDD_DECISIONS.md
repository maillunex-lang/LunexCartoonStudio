# Утверждённые решения Lunex Cartoon Studio v2

## GDD-01 — утверждено 2026-11-22
- EDITOR-001 **B**: простой + профессиональный режим с переключением.
- FORMAT-001 **B**: 2D, 2.5D, 3D и смешанные сцены.
- SCENE-001 **B**: Drag & Drop + готовые сцены + ручная настройка.
- ANIM-001 **B**: готовые движения + таймлайн + ключевые кадры.
- CAMERA-001 **B**: шаблоны камер + ручное движение и масштаб.
- PROJECT-001 **B**: сериалы, эпизоды, сцены, автосохранение и версии.
- DEVICE-001 **A** (уточнение утверждено 2026-11-22, заменяет B): полный редактор для создания мультфильмов на ПК; на смартфоне только просмотр проектов, без мобильного редактирования.
- DEMO-001 **C**: полноценный конструктор с экспортом длинных мультфильмов как критерий приёмки.

**Важное разделение:** утверждение функций GDD-01 не утверждает сторонние технологии. GitHub Research -> рекомендации -> отдельное согласование владельца -> внедрение -> тесты -> приёмка. Этап GDD-01 пока НЕ DONE.

Старые решения GDD v1 не действуют.

## Уточнение DEVICE-001
- Владелец подтвердил вариант **A**: desktop-first, полноценная работа в редакторе только на ПК; смартфон для просмотра проектов.
- Предыдущее DEVICE-001 B больше не действует. Не расширять мобильный редактор без нового утверждения.
- Факт утверждения не означает, что мобильный просмотр уже прошёл приёмочные тесты.

## GDD-01 EDITOR-002 — утверждено 2026-11-22
- **A**: переключатель «Простой / Профессиональный» в верхней панели редактора.
- Одна сцена, одни данные проекта и общий таймлайн; переключение меняет только представление и доступность панелей, без конвертации/потери данных.
- Техническая реализация и сторонние зависимости требуют отдельного TECH APPROVAL. Пока ничего не внедрено.

## GDD-01 TECH-EDITOR-002 — утверждено 2026-11-22
- **A**: адаптировать существующие React/Zustand/EditorPage/EditorToolbar, без новых библиотек.
- UI-only состояние режима, предпочтение отдельно от проекта; простая оболочка скрывает сложные панели, профессиональная показывает существующие инструменты.
- Переключение не меняет данные сцены и не создаёт undo/redo-запись. Реализация и тесты разрешены только в этих границах.

- Проверить лицензии, зависимости и сборку до заимствования кода; интегрировать поэтапно с тестами.
- DEMO-001 **C** остаётся в силе.
- GDD-02 не начинать до приёмки GDD-01.

## GDD-01 · Рубеж 08: ограничение экспорта, утверждено владельцем
- Максимальная длительность одного мультфильма: **5 минут (300 секунд)**. Это уточняет прежний критерий «длинных мультфильмов» в DEMO-001 C; часовой экспорт не требуется.
- Цель экспорта: серверный рендер на VPS, **MP4 H.264**, **1920×1080**, **30 FPS**, дополнительный **WebM**.
- Сегменты по **15–30 секунд**, контроль целостности и восстановление после сбоя.
- **Без звука на текущем этапе**.
- Приёмочные прогоны: **30 секунд, 1 минута, 3 минуты, 5 минут**; контролировать кадры, оба слоя 2D/3D, ресурсы и повторные попытки.
- Интерфейс: запуск экспорта, прогресс и получение готового видео.
- Утверждён план реализации, а не факт готовности. GDD-01 остаётся IN PROGRESS; к GDD-02 не переходить.
