# GDD Decisions - Lunex Cartoon Studio

## Утверждено
- **STUDIO-001 D**: автоматическая фабрика мультфильмов по сценарию, управляемая Codex.
- **ASSET-001 C**: гибрид Meshy AI (оригинальные модели) + готовые анимации с проверенной лицензией + Blender (ретаргетинг, сцены, рендер).

## Рабочие предположения, ещё не отдельные утверждённые решения
- Blender + Python + FFmpeg; FastAPI + PostgreSQL + React.
- Первая серия: Мишка, обучение счёту 1-10, 3 минуты, 16:9 1080p, без звука.
- Начальный каталог: целевой набор 50 анимаций, а не уже готовая библиотека.
- Сначала 15-секундный технический тест.
- Web Studio для каталогов, сценариев, предпросмотра и рендера.

Не менять утверждённые решения без согласования владельца.
