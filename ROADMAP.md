# Lunex Cartoon Studio - ROADMAP

Статус: PLANNED. Дата: 2026-11-22.
Цель: фабрика 3D-мультфильмов, где Codex превращает сценарий в сцены Blender, проверяемый предпросмотр и MP4.
Утверждено: ASSET-001 C - Meshy AI для оригинальных моделей + готовые лицензированные анимации + Blender для адаптации и постановки.
Первый пилот: Мишка учит считать от 1 до 10; 3 минуты, 16:9, 1080p, без звука. Сначала 15-секундный технический тест.
Принцип: никакой этап не DONE без артефакта и проверки; не объявлять генерацию моделей или анимаций реализованной без работающего интеграционного теста.

На каждом этапе: код + тесты + docs/STATUS.md + коммит в GitHub. Канон GDD менять только после согласования.

## Технические решения (предварительные)
Codex (оркестрация разработки и сценарной постановки), Blender + Python (сцены и рендер), FFmpeg (MP4), FastAPI (API), PostgreSQL (данные), React (панель). Blender headless поддерживается; скорость рендера на VPS нужно измерить на S02. Использовать JSON Schema для episode.json, отдельные manifest для персонажей и анимаций. Секреты Meshy только через переменные окружения. Для любых сторонних моделей и анимаций хранить лицензию, ограничения коммерческого использования и атрибуцию.

## Риски
Ретаргетинг между разными скелетами; качество переходов; лицензионная чистота; GPU/CPU бюджет рендера; ограничения API Meshy; движения с предметами и мимика. Для каждого риска нужен отдельный тест до массового производства.
