# Lunex Cartoon Studio

Новый старт проекта. Онлайн-студия создания 3D-мультфильмов в браузере.

## Принцип разработки
**GDD -> решение владельца -> поиск GitHub -> аудит лицензий и кода -> внедрение -> автоматические и ручные тесты -> приёмка -> следующий GDD.**

Ни один этап не считается завершённым только потому, что создан документ. Код и интеграция выполняются **после утверждения соответствующего GDD**, с проверяемыми результатами.

Текущий этап: **GDD-01, визуальный конструктор мультфильмов (на выбор)**.

Документы: [GDD-план](docs/GDD_PLAN.md), [GDD-01](docs/GDD_01_VISUAL_BUILDER.md), [правила разработки](AGENTS.md).
