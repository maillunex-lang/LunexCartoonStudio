# Lunex Cartoon Studio 🎬

Автоматизированная фабрика 3D-мультфильмов: Codex + Meshy AI + Blender + библиотека лицензированных анимаций.

**Статус:** проектирование, разработка ещё не начата. **Выбранный вариант:** ASSET-001 C (гибрид).

## Цель
Автор задаёт сценарий; система собирает storyboard, сцены, анимации и камеры, делает черновой просмотр, проверяет результат и рендерит MP4 после утверждения.

**Пилот:** 3-минутная серия «Мишка учится считать от 1 до 10», без звука, 1920×1080, 16:9. Первый технический тест - 15 секунд.
